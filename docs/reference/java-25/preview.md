# Java SE 25 preview source map

[Source map](README.md) · [Specification inventory](inventory/specifications.md#preview-editions)

The final [JLS preview list][jls-preview] identifies Primitive Types in Patterns, instanceof, and switch
as the Java 25 language preview. Consult its change specification alongside the base JLS. These URLs
identify different published editions of that preview, not three separate features.

| Published edition | Official source | Context |
| --- | --- | --- |
| `25+36-LTS-3489` | [Final platform preview][platform-preview] | JSR 400 Annex 3 baseline |
| `25-ea+33-LTS-3475` | [JLS-hosted preview][jls-hosted] | Earlier draft notice; retain its identity |
| `25.0.4+7-LTS-189` | [JDK-hosted preview][jdk-hosted] | Destination of the Oracle specifications catalog at observation |

The [JVMS preview list][jvms-preview] owns the VM boundary. Preview APIs have a separate
[API index][api-preview]. The [Vector API][vector] is an incubator module, not another language preview.
