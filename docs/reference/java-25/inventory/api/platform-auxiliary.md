## Publication identity

These source records belong to the final JSR 400 Annex 1 publication, independently of the later Oracle
release-25 documentation. All 21 modules, 182 packages, and 4,293 type pages were retrieved from this
publication. Their exact source links appear in the module/package inventories. This edition is not
silently replaced by the matching names in the Oracle publication.

The retrieved final API graph contains 4562 HTML source documents, including the
66 global/auxiliary pages below. Its 4657 generated hierarchy/use destinations are also linked
from the owning package/type inventories. Navigation is **Context**, not a separate language rule.

## References outside the published module set

The final `java.naming` module links to two JDK provider module pages under the final API root.
Both destinations returned HTTP 404. Neither module belongs to the 21-module platform API index.
The combined Oracle publication has separately identified contracts for these providers. Those
contracts are cross-references, not silent replacements for the unavailable final-publication URLs.

- `jdk.naming.dns`: [Unavailable final-publication destination][source-208]; [Referring java.naming
  contract][source-209]; [Oracle provider contract][source-210].
- `jdk.naming.rmi`: [Unavailable final-publication destination][source-211]; [Referring java.naming
  contract][source-209]; [Oracle provider contract][source-212].

Status of the two final-publication destinations: **Unresolved identity** at the published destination.
The observation concerns the published links, not the presence of the providers in a JDK installation.
