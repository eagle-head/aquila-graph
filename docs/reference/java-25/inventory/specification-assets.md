# Specification figures and supporting documents

[Source inventory](README.md) · [Specification inventory](specifications.md) · [Dependencies](dependencies.md)

This catalog records embedded figures and directly linked PDF/plain-text supporting
documents in the current Oracle narrative/tool specifications, final-platform narrative
annexes, JLS/JVMS chapter bodies, and the two Oracle preview publication variants. Each
record retains the target address and its referring specification location.

Resource type describes presentation. It does not determine normative authority: a figure
belongs to its owning passage, while a linked external standard derives applicability from
the clause that incorporates it. No record below is counted as an additional Java language
feature. Distinct Oracle and final-platform addresses remain distinct publication records.

Mapping: each record retains its official publication identity.
The external addresses are preserved as published, including older RFC and FIPS locations;
destination content and edition equivalence are not established by link presence alone.

Target records: 28. These records identify assets and supporting documents, not
the number of specification clauses or independent subject areas.

## Source boundaries

No separately linked schema, code archive, or source-code download was observed among
these specification resource references. That statement is limited to the inspected
publication bodies; inline schemas, examples, and pseudocode remain content of their
owning documents. The [API inventory](api/README.md) separately owns API `doc-files`
schemas and supporting resources. [Guide assets](guides/assets.md) own guide figures
and downloads. Website logos, CSS, and scripts are presentation infrastructure.
