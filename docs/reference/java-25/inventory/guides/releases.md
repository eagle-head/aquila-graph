# Oracle JDK 25 release and compatibility sources

[Guide inventory](../guides.md)

Role: Oracle JDK release history, implementation changes, compatibility information,
and update-specific notes. These records complement the Java SE 25 specifications.
They are not additional language grammar or a claim that each implementation change
is a new Java SE normative requirement.

The source set includes the official release index, consolidated notes, readme, and
the Java 25 release-note documents linked among those sources. Fragment-only
sections such as GA and BPR entries remain in their owning document. Records were observed
on October 30, 2026; updates to these mutable pages require a new inventory observation.

Mapping: Source mapped.
