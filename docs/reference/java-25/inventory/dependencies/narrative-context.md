# Context and cross-release references

[Dependency inventory](../dependencies.md)

This register preserves outgoing links from the body of all 82 HTML documents reached within the current
Oracle release-25 specification catalog, 42 narrative documents from the published JSR 400 platform copy, all
19 JLS chapters, all seven JVMS chapters, and the separately published language-preview document. Links into
the current Oracle release-25 API, guides, and language/VM specifications belong to the source inventories;
other web destinations are retained here.

Each record retains the exact target and referring section. Repeated identical target/origin/label occurrences
are combined, while distinct labels and sections remain separate. Presence is evidence of a source
relationship, not proof that every clause of a linked document is normative for Java.

Records: 44 distinct targets; 56 origin/section/label relations.

Mapping status for these records: registered external dependencies or contextual references; the target
full texts are not included by this inventory. Source editions are not silently upgraded.
