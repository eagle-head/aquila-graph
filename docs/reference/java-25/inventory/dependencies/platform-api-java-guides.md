# Published platform: API references to Java guides

[Dependency inventory](../dependencies.md)

This register preserves links outside the release-25 API tree found in the published JSR 400 final platform
API HTML documents. It includes ordinary prose links in addition to declared External Specifications records.
Exact target URLs and source anchors are retained; duplicate target/source/anchor/label combinations are
combined.

Edge type: API source reference. A link does not, by itself, incorporate the whole target as a normative
requirement. Read the referenced source passage to determine its force and extent. The source anchor is the
nearest identified source location; a declaration may contain several links and labels. Existing source
records control local-text and edition status.

Records: 17 distinct targets; 62 source/anchor/label relations.

Five recurring footer link pairs are recorded once in the dependency inventory instead of being repeated for
every API document. No other external link category is excluded.
