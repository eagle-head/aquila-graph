# Annotated differences: API references to IETF specifications

[Dependency inventory](../dependencies.md)

This register preserves links outside the release-25 API tree found in the 4,412 successfully retrieved
annotated API-difference HTML documents in JSR 400 Annex 2. It includes ordinary prose links in addition to
declared External Specifications records. Exact target URLs and source anchors are retained; duplicate
target/source/anchor/label combinations are combined.

Edge type: annotated-difference source reference. Role: Context. The publication compares jdk-24-ga and
jdk-25+36; references can occur in retained, inserted, removed, or changed text. None is promoted
automatically to a Java 25 normative obligation. Origin links identify the exact comparison page; the nearest
heading is named where present. The complete extracted link labels preserve the publication's old/new
destination descriptions. Existing source records control target identity and mapping status.

Records: 50 distinct targets; 69 source/heading/label relations.

Changed footer references and their annotated labels are retained. No outbound target category is excluded
from this comparison register.
